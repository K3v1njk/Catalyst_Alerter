Personal software project

Biotech event intelligence without the noise.

Catalyst Alerter is a serverless monitoring project that watches publicly available FDA, ClinicalTrials.gov, SEC EDGAR, and financial-news sources for meaningful biotech regulatory and clinical events, then sends alerts when something genuinely new appears.

View SMS use & consent View project on GitHub

About the project

The system is built and operated by the author for personal event monitoring. It is not a brokerage, investment adviser, marketing platform, or public SMS subscription service.

Regulatory monitoring

Tracks public FDA and regulatory signals relevant to configured biotech catalysts.

Clinical-trial monitoring

Checks ClinicalTrials.gov and company disclosures for important trial updates and readouts.

Event filtering

Uses attribution, freshness, deduplication, and event classification to reduce repetitive or unrelated alerts.

How it works

A scheduled AWS workflow polls independent public sources, normalizes the results, associates content with the correct tracked drug or program, classifies the event, compares it with stored state, and sends an alert only when the event is new and relevant.

AWS Lambda Amazon EventBridge Amazon DynamoDB Amazon SNS Python FDA data ClinicalTrials.gov SEC EDGAR

SMS alert use

SMS alerts are intended only for the project operator's own phone number. There is no public marketing list, no purchased contact list, and no third-party promotional messaging.
PurposeTime-sensitive regulatory and clinical-event notifications. AudienceThe account owner / project operator only. Expected volumeVariable; typically low-volume and event-driven. ConsentManaged by the account owner through the AWS notification subscription. Opt-outThe owner can unsubscribe from the AWS SNS subscription at any time.
